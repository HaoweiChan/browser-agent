Annual report picker

The picker below is the T-M42-20-D5 shape and it is not contrived: a filing list keyed by FISCAL year whose labels name the CALENDAR year is how regulators publish them, so option 2's VALUE is exactly option 3's LABEL. The string "2024" therefore names two different filings by two different fields, and a matcher that searches the (value, label) pair and takes the first hit selects one of them, reads it back against its own match, and reports success.
